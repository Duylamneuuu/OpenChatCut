OpenChatCut Custom - Windows x64

Extract the complete ZIP into a writable folder on your chosen drive.
Run Start-OpenChatCut.cmd so projects, media, models, and Electron data are kept
under data\OpenChatCut beside the app. The launcher uses that folder for temp files.

Move the entire folder when moving a portable installation. Back up the data folder
before replacing a working installation. The ZIP does not contain user projects,
login sessions, cloud API keys, or downloaded AI model packs.

Choose a signed-in CLI in the chat model selector. Ask reads and explains your
project; Agent can edit it. Codex, OpenCode, and Antigravity are separate options.
Install external CLI tools separately if they are not already installed.

Custom releases and source:
https://github.com/Duylamneuuu/OpenChatCut/releases
https://github.com/Duylamneuuu/OpenChatCut/tree/agent/color-grading-ai

This Windows build is unsigned. No macOS or Linux binaries are included.
